# 文亚宇宙世界观 Wiki 模板使用指导

> 模板示例页见 `wiki_dump/articles/`（人物模板示例、机构模板示例、理论信息框模板）。

## 一、信息框模板（5 种）

条目顶部使用信息框，参数可选，没有的内容留空不显示。**下表为快速参考，参数定义以 `references/templates/` 镜像内模板源码为准。**

**注意：镜像 `articles/枪毙.wiki` 使用了第 5 种 `{{Concept}}` 信息框，但该模板源码未收录在 `templates/` 目录（Live 站存在，镜像缺源）。写概念/主张类条目时可参考它的用法。**


### 1. Template:Character 人物模板

```wiki
{{Character
|name=
|image=
|caption=
|foreign_name=
|birth_date=
|birth_place=
|occupation=
|affiliation=
|position=
|colleagues=
|fields=
|rival=
}}
```

| 参数 | 说明 | 示例 |
|------|------|------|
| name | 人物姓名，一般自动读取页面名称 | 孙笑川教授 |
| image | 图片文件名（不加 `File:`） | 孙笑川教授.png |
| caption | 图片说明 | 孙笑川教授 |
| foreign_name | 外文名 | 亀田小川教授 |
| birth_date | 出生日期 | 1990年5月12日 |
| birth_place | 出生地 | 疑似生于日本京都御所 |
| occupation | 职业/身份 | 理论物理学家、科学管理学者 |
| affiliation | 所属机构 | [[114514研究所]]（创始人兼主任） |
| position | 主要职务 | 武汉大学理论物理学院教授 |
| colleagues | 同事 | [[侯国玉教授]]、[[刘建龙教授]] |
| fields | 研究领域 | 引力理论、天体动力学 |
| rival | 主要争议对象 | [[李文亚]] |

## 二、辅助模板

| 模板 | 用途 | 参数 |
|------|------|------|
| `{{维护提示\|icon=\|title=\|text=\|category=}}` | 页面维护提示条（设定冲突、内容待补） | icon（默认⚠️）、title、text、category |
| `{{Stub}}` | 小作品标记，挂于简短条目页尾 | 1（可选补充说明） |
| `{{引言\|title=\|text=\|author=}}` | 竖排引言块，用于人物原话引用 | title（可选）、text（必填）、author |
| `{{来函\|title=\|text=\|author=}}` | 来函块，用于引用网友/机构来信 | title（可选）、text（必填）、author |
| `{{Main\|主条目}}` | 主条目导航 |
| `{{See_also\|…}}` | 参见导航 |
| `{{Further\|…}}` | 延伸阅读导航 |
| `{{Hatnote\|…}}` | 顶注消歧义 |
| `{{Quote\|…}}` | 引用块 |
| `{{Cite_web\|…}}` | 网络引用 |
| `{{Delete}}` | 提请删除 |
| `{{Disambiguation}}` | 消歧义 |
| `{{批判李文亚大会系列}}` | 批判大会系列导航卡片（页底调用，无参数） |

**维护提示示例**（设定冲突时必用，配合 `.wy-maintenance` 样式）：

```wiki
{{维护提示|icon=⚠|title=本页面存在设定冲突|text=本页面描述的内容与外部资料存在冲突。|category=设定冲突的页面}}
```

## 三、页面推荐结构

### 人物条目骨架

```wiki
{{Character|name=…|…}}

'''全名'''（外文名，生年－），一句话定义（身份、所属、研究方向）。

== 生平 ==
=== 早年经历（如果有） ===
=== 学术/研究经历（如果有） ===
== 研究成果 ==   （可用 === 子章节 === 分列各成果，每项以 '''加粗名''' 开头）
== 争议 ==        （如有）
== 评价 ==        （支持者认为…／批评者认为…，保持双方视角）
== 相关条目 ==    （* [[…]] 列表）

[[分类:李文亚宇宙人物]]
```

### 机构条目骨架

```wiki
{{Institutions|…}}

'''机构全名'''（外文名），一句话定义（类型、地位）。

== 概要 ==
== 机构概况 ==
== 历史 ==
=== 创立 ===
=== 发展 ===
== 学术方向 ==
== 争议 ==
== 评价 ==
== 相关条目 ==

[[分类:李文亚宇宙机构]]
```

### 理论条目骨架

```wiki
{{Theory|…}}

'''理论名'''是[[李文亚]]提出的……。

== 内容 ==
（分类假说/结构模型/致病机制等，用 '''加粗名''' 分项）
== 相关条目 ==

[[分类:李文亚宇宙理论]]
```

### 事件条目骨架

```wiki
{{Event|…}}

== 概述 ==
== 背景 ==
== 过程 ==
== 结果与影响 ==
== 参会主要人物 ==   （* [[…]] 列表）
== 参见 ==

[[分类:事件]]
```

## 四、命名规则

- **人物统一用「XX教授」形式**：没有「卢初雪」，只有「[[卢初雪教授]]」。
- **李文亚除外**：没有「李文亚教授」，教授是对他的尊称。特殊条目还有「[[李文亚（清醒人格）]]」。
- **镜像中已有例外（按现状照写，不新建重定向页）**：`唐振钦`、`王楚淇` 的正文页在镜像里不带「教授」后缀（信息框 name 仍写「XX教授」，但 `唐振钦教授` 是红链、`王楚淇教授` 重定向到 `王楚淇`）；`二向箔的投放者` 同理。新人物一律用「XX教授」；遇到这些已有例外时跟随页面现状。
- 引用时保持写法一致，避免分裂红链。
- 机构/学校/概念/事件用全名，不缩写。

## 五、分类规则

使用中文命名空间 `[[分类:…]]`，**不要**用 `Category:`。现有分类见 `wiki_dump/categories.txt`，常用：

| 条目类型 | 分类 |
|----------|------|
| 人物 | `[[分类:李文亚宇宙人物]]` |
| 机构 | `[[分类:李文亚宇宙机构]]` |
| 理论/概念 | `[[分类:李文亚宇宙理论]]`、`[[分类:文亚宇宙概念]]`、`[[分类:李文亚的主张]]`、`[[分类:李文亚的理论]]` |
| 事件 | `[[分类:事件]]` |
| 其他常用 | `[[分类:批判李文亚大会]]`、`[[分类:批判孙笑川大会]]`、`[[分类:114514研究所]]`、`[[分类:孙笑川团伙]]`、`[[分类:黑体生物]]`、`[[分类:争议理论]]`、`[[分类:枪毙名单]]`（枪毙类）、`[[分类:反对李文亚势力]]`、`[[分类:医学理论]]`/`[[分类:生命科学理论]]`（医学/生物类）、`[[分类:江南大学]]`（唐振钦） |

其余分类见 `wiki_dump/categories.txt`（含 学术评价学者、科学管理学者、日本理论物理学家、德意志图勒研究学会、诺奖与民科研究交流协会、大学、索引 等），新建条目时按主题挂载。

## 六、索引列表

创建条目后必须加入对应索引列表页，否则条目不会在站内导航中出现：

- 人物 → [[教授列表]]
- 机构 → [[机构列表]]
- 学校 → [[学校列表]]
- 概念/理论 → [[概念列表]]
- 事件 → [[事件]]

**索引排序**：按拼音首字母分组（A–Z + #），排序优先级为「无」>数字>字母>符号。
例：`李文亚` 在 `李文亚（清醒人格）` 之前（更短优先）；`刘建龙教授` 排在 `李文亚` 前（liujianlong < liwenya）；`114514` 在数字区最前；`《》` 在符号区最后。

## 七、编辑规则与写作规范（依据写作指南 2026-08 版）

1. **开篇必有加粗定义句**：`'''条目名'''（外文名，…），…`，仿维基百科体例。
2. **语气中立**：百科式中立叙述外壳（「据称」「支持者认为」），避免个人立场倾向。
3. **图片一律 AI 生成**（推荐 GPT-Image2 等），不得使用真人照片；`image` 填文件名不加 `File:`。
4. **不套用现实著名人物/争议人物真名**；不为现实中存在的机构创建带原创元素的条目。
5. **尊重李文亚本人**：严禁骚扰、辱骂、诽谤；创作属于戏仿叙事。
6. **避开政治敏感内容和社会议题及涉黄、涉恐、色情、过度血腥暴力等具有不良影响内容的创作**。
7. **允许创作李教授未读过的内容**，但涉及理论来源/历史真实性时标注「事实争议」。
8. **学术背景可自由编造，但逻辑要自洽**；非贯穿全剧的角色，提到它的视频需用注释引用，最好加时间戳链接（参考 [[卢初雪教授]]、[[比格·迪克·查斯利·温雅教授]]）。
9. **大量内部链接** `[[…]]` 构成条目互联网络。
10. **遵守 CC-BY-SA 许可协议**；无意义编辑、无理由删除与编辑战视为破坏。
11. **对他人作品保持包容**：建议可严厉但须有建设性，禁止直接辱骂、贬低。
12. **禁止广告、推广、引流**；创建条目后必须加入对应索引列表（见第六节）。

## 八、AI Agent 工作流程

1. 判断条目类型：
   - 人物 → `Character`
   - 机构/学校/国家/组织 → `Institutions`
   - 理论/学说/定律 → `Theory`
   - 概念/主张/诉求（如 枪毙） → `Concept`（镜像缺源码，参考 `articles/枪毙.wiki`）
   - 事件/奖项/大会 → `Event`
2. 先读镜像作为上下文：`wiki_dump/articles/` 中同名或同类条目 + 对应模板源码（`wiki_dump/templates/*.wiki`）。
3. 首先生成信息框模板，再生成正文（按第三节骨架）。
4. 检查：
   - Wiki 语法正确、内部链接指向现有条目或按命名规则新页
   - 加粗定义句、章节标题齐全
   - 分类正确（中文命名空间）、已挂维护提示/Stub（如需）
   - 世界观一致性（对照 `liwenya-universe` 设定）、命名一致性（XX教授/李文亚）
   - 是否有用户输入数据或 wiki 镜像/网络内容支撑，避免胡编乱造
5. 输出最终 MediaWiki 页面代码（含分类），并提示用户加入对应索引列表。
