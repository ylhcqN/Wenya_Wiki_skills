## 一、信息框模板（5 种）

条目顶部使用信息框，参数可选，没有的内容留空不显示。**下表为快速参考，参数定义以 `references/templates/` 镜像内模板源码为准。**

**注意：镜像 `articles/枪毙.wiki` 使用了第 5 种 `{{Concept}}` 信息框，但该模板源码未收录在 `templates/` 目录（Live 站存在，镜像缺源）。写概念/主张类条目时可参考它的用法。**


### 1. Template:Character 人物模板

```wiki
{{Character
|name=
|image=
|caption=
|foreign_name=
|birth_date=
|birth_place=
|occupation=
|affiliation=
|position=
|colleagues=
|fields=
|rival=
}}
```

| 参数 | 说明 | 示例 |
|------|------|------|
| name | 人物姓名，一般自动读取页面名称 | 孙笑川教授 |
| image | 图片文件名（不加 `File:`） | 孙笑川教授.png |
| caption | 图片说明 | 孙笑川教授 |
| foreign_name | 外文名 | 亀田小川教授 |
| birth_date | 出生日期 | 1990年5月12日 |
| birth_place | 出生地 | 疑似生于日本京都御所 |
| occupation | 职业/身份 | 理论物理学家、科学管理学者 |
| affiliation | 所属机构 | [[114514研究所]]（创始人兼主任） |
| position | 主要职务 | 武汉大学理论物理学院教授 |
| colleagues | 同事 | [[侯国玉教授]]、[[刘建龙教授]] |
| fields | 研究领域 | 引力理论、天体动力学 |
| rival | 主要争议对象 | [[李文亚]] |

## 四、命名规则

- **文亚宇宙原创人物统一用「XX教授」形式**：没有「卢初雪」，只有「[[卢初雪教授]]」。
- **李文亚例外**：正文页为「[[李文亚]]」（无「教授」后缀，因教授是对他的尊称）；`李文亚教授` 现作为**重定向页**指向 `李文亚`，勿新建独立正文。另有「[[李文亚（清醒人格）]]」。
- **已确认的非「XX教授」人物例外（按页面现状照写，不新建重定向）**：
  - `唐振钦`、`王楚淇`：正文页不带「教授」后缀，`唐振钦教授`/`王楚淇教授` 为重定向到对应正文页。
  - `二向箔的投放者`：正文页不含「教授」后缀（信息框 name 写「二向箔投放者」）。
  - `马斯勒`：正文页为 `马斯勒`，`玛斯勒` 为跨命名空间重定向。
  - `明日香`：正文页为 `明日香`，`明日香教授` 为重定向到 `明日香`。
  - 其他头衔变体：`童子军大王博士`（博士）、`特罗菲姆·李森科院士`（院士）。
  - 以上人物信息框 `name` 仍按规则写「XX教授／博士／院士」等正式头衔，但**页面标题与内部链接**跟随上述现状。
- **跨作品客串 / 现实引用人物不使用「XX教授」**（如 `巴巴托斯`、`贝利亚大帝`、`博丽灵梦`、`布雷斯维特夫人`、`芙宁娜·德·枫丹`、`港塞`、`绫波丽`、`撒贝宁`、`乌弗瑞克`、`噫噫呜呜`、`梅玛`、`蜜桃乌龙`、`爱吃鱼的猫`、`爱因斯坦算命先生`、`斯卡里茨的亨利` 等，非穷尽），按页面现状照写，不强行加「教授」。
- 新原创人物一律用「XX教授」；遇到上述已有例外时跟随页面现状，引用保持写法一致，避免分裂红链。
- 机构/学校/概念/事件用全名，不缩写。

## 六、索引列表

创建条目后必须加入对应索引列表页，否则条目不会在站内导航中出现：

- 人物 → [[教授列表]]
- 机构 → [[机构列表]]
- 学校 → [[学校列表]]
- 概念/理论 → [[概念列表]]
- 事件 → [[事件]]

**索引排序**：按拼音首字母分组（A–Z + #），排序优先级为「无」>数字>字母>符号。
例：`李文亚` 在 `李文亚（清醒人格）` 之前（更短优先）；`刘建龙教授` 排在 `李文亚` 前（liujianlong < liwenya）；`114514` 在数字区最前；`《》` 在符号区最后。

## 七、编辑规则与写作规范（依据写作指南 2026-08 版）

1. **开篇必有加粗定义句**：`'''条目名'''（外文名，…），…`，仿维基百科体例。
2. **语气中立**：百科式中立叙述外壳（「据称」「支持者认为」），避免个人立场倾向。
3. **图片一律 AI 生成**（推荐 GPT-Image2 等），不得使用真人照片；`image` 填文件名不加 `File:`。
4. **不套用现实著名人物/争议人物真名**；不为现实中存在的机构创建带原创元素的条目。
5. **尊重李文亚本人**：严禁骚扰、辱骂、诽谤；创作属于戏仿叙事。
6. **避开政治敏感内容和社会议题及涉黄、涉恐、色情、过度血腥暴力等具有不良影响内容的创作**。
7. **允许创作李教授未读过的内容**，但涉及理论来源/历史真实性时标注「事实争议」。
8. **学术背景可自由编造，但逻辑要自洽**；非贯穿全剧的角色，提到它的视频需用注释引用，最好加时间戳链接（参考 [[卢初雪教授]]、[[比格·迪克·查斯利·温雅教授]]）。
9. **大量内部链接** `[[…]]` 构成条目互联网络。
10. **遵守 CC-BY-SA 许可协议**；无意义编辑、无理由删除与编辑战视为破坏。
11. **对他人作品保持包容**：建议可严厉但须有建设性，禁止直接辱骂、贬低。
12. **禁止广告、推广、引流**；创建条目后必须加入对应索引列表（见第六节）。

## 八、AI Agent 工作流程

1. 判断条目类型：
   - 人物 → `Character`
   - 机构/学校/国家/组织 → `Institutions`
   - 理论/学说/定律 → `Theory`
   - 概念/主张/诉求（如 枪毙） → `Concept`（镜像缺源码，参考 `articles/枪毙.wiki`）
   - 事件/奖项/大会 → `Event`
2. 先读镜像作为上下文：`wiki_dump/articles/` 中同名或同类条目 + 对应模板源码（`wiki_dump/templates/*.wiki`）。
3. 首先生成信息框模板，再生成正文（按第三节骨架）。
4. 检查：
   - Wiki 语法正确、内部链接指向现有条目或按命名规则新页
   - 加粗定义句、章节标题齐全
   - 分类正确（中文命名空间）、已挂维护提示/Stub（如需）
